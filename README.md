# Smart Student Task Manager

## About the Project
Smart Student Task Manager is a Python-based desktop application designed to help college students organize their academic tasks and manage deadlines.

## Problem Statement
Students often forget assignment deadlines and struggle to manage multiple academic activities.

## Proposed Solution
This application provides a simple platform to add tasks, set deadlines, assign priorities and track task completion.

## Features
- Add assignments and academic tasks
- Set submission deadlines
- Set task priorities
- View pending tasks
- Identify overdue tasks
- Mark tasks as completed
- Delete tasks
- Save data using JSON

## Technologies Used
- Python
- Tkinter
- JSON

## How to Run
1. Install Python.
2. Download the repository.
3. Open the project folder in VS Code.
4. Run `python main.py` in the terminal.
